# 4-minute judge flow

1. Start `run.bat` and upload a challenge video.
2. Keep Detection stride at 3 for the default speed/temporal trade-off.
3. Run the full analysis and show the progress + processing factor.
4. Show Risk timeline with track IDs, timestamp, confidence, risk score and evidence frame.
5. Open an evidence frame and explain: observed behaviour -> potential risk -> intervention.
6. Ask the supervisor assistant: `What are the most common risky behaviours?`
7. Download the JSON audit artifact.
8. Emphasize that behaviour decisions come from open-vocabulary perception, persistent tracking and temporal geometry rather than filenames or hard-coded challenge timestamps.
